# P-054. OpenClaw Desktop повторял устаревший запрос `Approve Mac`

[English version](en/P-054.md)

**Статус доказательств:** подтверждено записями о техобслуживании от 2026-07-15. Исправление выполнялось на стороне Desktop; авторизацию устройства на VPS не сбрасывали.

## Когда и в каких условиях
2026-07-15. iMac OpenClaw Desktop 2026.6.11 работал с VPS Gateway 2026.7.1.

## Симптомы
Desktop снова показывал `Approve Mac`; подтверждение не помогало. На Gateway не было ожидающих запросов, а iMac отображался как approved/connected.

## Разделение наблюдений и действий
Оператор проверил состояние Gateway, список ожидающих запросов и уже одобренный узел, сделал локальную резервную копию для восстановления и разрешил штатное обновление Desktop. Pairing records, маршруты, MCP и permissions не трогали.

## Причинная гипотеза
Старый Desktop повторял устаревший request ID, которого Gateway уже не знал. Это был клиентский цикл устаревшего approval, а не новая заявка на доступ.

## Что не сработало бы
Сброс устройств, удаление paired node или ручная замена bundle могли создать новый инцидент вместо ремонта существующего.

## Что помогло
Помогло сначала доказать отсутствие pending request, затем обновить устаревший Desktop через проверенный updater и перезапустить только приложение.

## Проверка результата
После обновления установленное приложение и запущенный Desktop были версии 2026.7.1; тот же узел оставался approved/connected; pending requests и новые ошибки unknown request отсутствовали.

## Ограничения
Если Gateway действительно показывает новый pending request, это уже другая процедура.

## Основание
Основание: ограниченные по области записи Brain о техобслуживании, уроках и каноне, а также история git этой ветки документации. Сырые журналы, приватные пути, домены/IP, email, секреты и конфигурации намеренно не публикуются.
