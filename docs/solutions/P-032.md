# P-032. Cloudflare и Netlify были доступны несимметрично

[English](en/P-032.md) · [Индекс](../problem-index.md)

**Статус:** частично подтверждено: Netlify и исправленный Cloudflare account-token прошли проверки, но это не является полным deploy-smoke для каждого сервиса.

## Условия и симптомы

24 мая 2026 года стек агентов должен был уметь публиковать небольшие веб-артефакты и управлять периметром. Netlify API читался успешно, а проверка Cloudflare через конечную точку user-token возвращала 401. При этом Cloudflare Access для публичных маршрутов продолжал работать, поэтому нельзя было делать вывод, что сломан весь Cloudflare.

## Причина и проверяемая гипотеза

Проверка показала несоответствие типа токена и конечной точки. Токен был уровня аккаунта, а его проверяли как user-token. Эти контуры нужно различать:

```sh
# user token: /user/tokens/verify
# account token: /accounts/<account_id>/tokens/verify
```

Cloudflare Access, DNS/deploy API и Netlify API — разные поверхности. Успех одной не доказывает работоспособность другой, а 401 на неверной конечной точке verify не доказывает отказ периметра Access.

## Что помогло и что не трогали

После подтверждения владельцем значения токена обновили в закрытых env-файлах. Watchdog изменили так, чтобы он проверял account-token через account endpoint, затем перезапустили два gateway. DNS, Access apps, Workers, Pages и записи zone records в этой операции не менялись.

Не помогало пытаться «чинить публикацию» через ослабление Cloudflare Access. Запись прямо разделяет периметр Access и состояние API-token.

## Проверка и ограничения

В записи указано: account-token verify вернул active, watchdog после ручного запуска сообщил восстановление, оба gateway стали active. Netlify к тому моменту подтверждался чтением аккаунта и проектов. Ограничение: отдельный post-repair Cloudflare MCP read/deploy smoke не зафиксирован, поэтому статус не должен превращаться в «всё Cloudflare/Netlify полностью проверено».

## Основание

Внутренние записи: «Cloudflare and Netlify Deploy Capability Priority» от 2026-05-24 и последующий блок Cloudflare token repair. Токены, аккаунтные идентификаторы, домены и сырые логи не публикуются.
