# P-026. Notion MCP ломал строгую проверку схем инструментов

**Статус:** подтверждённый обход: read-only Notion MCP оставлен рабочим; write/mutation tools этим ремонтом не восстановлены.

[English version](en/P-026.md)

## Симптом
При подключении Notion MCP с mutation tools агентский клиент падал или отказывался отвечать из-за строгой проверки схем инструментов. Ошибка выглядела как provider-side schema/invalid_function_parameters, а не как недоступность Notion API.

## Условия
Инцидент связан с Hermes/OpenClaw runtime, использующим строгую function/tool schema validation. Notion MCP v2.x отдавал набор инструментов, где часть write-tools имела схему, несовместимую с клиентской валидацией. Для пользователя важнее было сохранить поиск и чтение Notion, чем рисковать всем ответным контуром ради записи.

## Причина
Проблемными были отдельные mutation tools Notion, включая создание data source и patch page. Их JSON schema не проходила строгую валидацию клиента. Это не доказывало плохой token: read-only Notion self/page/list сценарии в других проверках проходили.

## Что было сделано
Операторы ограничили Notion MCP проверенным read-only набором: поиск, чтение страниц, блоков и data source. Это был намеренный safe-mode, а не полное отключение Notion. Write-tools должны возвращаться только после отдельной проверки схем на текущих версиях и отдельных mutation smoke.

## Проверка результата
После ограничения gateway оставался active, основной smoke проходил, стресс-серия ответов завершилась без schema/HTTP 400/invalid_function_parameters в свежем журнале. Более поздние регистры фиксируют Notion MCP как standalone/Hermes-facing capability, но запись Talos/OpenClaw для Notion не следует автоматически включать без валидного token и smoke.

## Ограничения
Этот ремонт не восстанавливает создание или изменение страниц Notion через MCP. Он доказывает только, что read-only режим убрал schema-breaker из общего toolset и позволил агенту отвечать стабильно.

## Практический вывод
Не смешивайте schema 400 с auth 403. Если strict client ломается на MCP tool schema, сначала сузьте tool allowlist до read-only, сохраните полезное чтение и отдельно тестируйте mutation tools. Смежные неподтверждённые 403/env случаи описаны в [P-027](P-027.md) и [P-028](P-028.md).
