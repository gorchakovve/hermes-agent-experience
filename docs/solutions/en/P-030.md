# P-030. The first attempt to bind Workspace MCP to localhost stopped the service

**Status:** confirmed final hardening; the first failed attempt was not traced to an exact public error line.

[Русская версия](../P-030.md)

## Symptom
The first attempt to restrict Workspace MCP binding to localhost caused the service to fail at startup. This was a hardening change: remove external bind without losing the local MCP endpoint used by Hermes/Talos.

## Conditions
Before hardening, the service already worked on the VPS. The requirement was to preserve streamable HTTP/MCP compatibility and two-account access while making the listener loopback-only. Unlike [P-029](P-029.md), this case is about network bind, not entrypoint/argument selection.

## Cause or accepted workaround
The postmortem confirms the failed first attempt and rollback, but does not include enough public-safe detail to name the exact failing line. The successful implementation used the supported loopback bind setting, leaving the known-working entrypoint intact.

## Actions taken
The first variant was rolled back. Operators then added the host override in the protected service environment, restarted Workspace MCP, and verified that it listened only on loopback. Public/external access to the port became unavailable, while local health and MCP initialize still worked.

## Verification
The service was active, the listener was loopback-only (`127.0.0.1:<service-port>`), local health was healthy, MCP initialize/list-tools passed, and direct access to the port from outside was blocked/unreachable. Read-only Workspace checks for two accounts passed on the hardening date.

## Limitations
This is a confirmed workaround and final smoke, not a complete root-cause analysis of the first failed attempt. If a future client must connect from another host, do not simply restore public bind; design a separate tunnel, firewall, and auth decision.

## Operational lesson
For service hardening, change one axis at a time: preserve the working entrypoint, set the supported loopback bind, then verify the listener, local MCP smoke, and external denial. Do not patch package/cache code for bind if the service already supports configuring its listen address.
