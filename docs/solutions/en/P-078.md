# P-078. Honcho promoted temporary tasks into the user profile

**Status:** confirmed as a targeted cleanup. Profile cards were replaced with a curated set, noisy conclusions were removed selectively and read back; a full history audit was not performed.

**Русская версия:** [P-078](../P-078.md)

## Timeframe and conditions
2026-09-26. Scope: Honcho workspace, the user's peer and Hermes→user / user→user observer relationships. Brain remained canon; Honcho was treated as a personalization/context layer, not the source of truth.

## Symptoms
Active context contained third-party text, transient browser/tool events, one-off tasks and statuses as if they were durable facts about the user. Old self-card rules could also turn one-time constraints into permanent preferences.

## Confirmed cause vs hypothesis
Confirmed: automatic summarization did not reliably separate biographical/long-term facts from third-party material and short-lived operations. Before cleanup the workspace had tens of thousands of conclusions, and the target cards had dozens of facts, some unsuitable as durable profile data.

Hypothesis: noise may return if old source messages are reprocessed. This is an honest limitation because source messages were not deleted.

## Actor attribution and actions
The operator created a private backup of cards/conclusions, replaced the two target cards with the same curated 13-item profile, and removed exactly 114 individually reviewed noisy conclusions. Sessions, messages, workspace, general project conclusions and sensitive source material were not deleted.

What would not be safe: “wipe all memory” or re-import the backup wholesale. That would lose useful context and could restore noise.

## Practical verification
Order for a similar cleanup:

```sh
honcho export --scope <peer> --output <private-backup>
honcho card get <observer> <target>
honcho conclusion delete <id>
honcho context get <peer>
```

Commands are generic; use the real API/CLI in your environment. The key is: private backup, delete by reviewed IDs, read cards back, then sample active context for removed noise.

## Proof of result
Confirmed: both target cards read back with the same curated 13-item set; all 114 deleted IDs returned not found; active context no longer contained the checked noisy example; Honcho remained connected.

## Limits and open items
This was not a full review of every conclusion. Source messages remain, and the card hygiene statement is not a server-side ingestion filter. Periodic active-context checks and a separate filtering design are needed if noise returns.

## Lesson
Personal memory should store durable facts and preferences, not raw task material. Repair targeted cards and reviewed conclusions; do not wipe the whole memory blindly.
