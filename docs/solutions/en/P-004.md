# P-004. Scheduled updater used a Node.js version below the package engine floor

**Status:** confirmed by the 2026-09-16 update note.

**Evidence:** MAINTENANCE note from 2026-09-16; direct comparison of system Node, package engine floor, dedicated runtime, service executable, and updater result. Raw logs, private paths, tokens, domains, and addresses are intentionally omitted.

**RU:** [`P-004.md`](../P-004.md)

## Symptoms
Scheduled OpenClaw updates stopped completing after the package raised its minimum Node.js requirement.

## Conditions and timing
VPS, 2026-09-16; OpenClaw update 2026.9.2 → 2026.9.4.

## Hypothesis / root cause
System Node was below the package’s new engine floor. The updater and service/CLI needed a pinned runtime, but changing system Node would have widened risk.

## Actions that worked
Installed a separate official Node runtime, verifying the archive against the official SHA-256 manifest; pinned it for the service/CLI and fixed the weekly updater PATH. System Node and the Hermes runtime were not changed.

## Verification
The updater completed, the gateway used the dedicated Node runtime, the CLI reported 2026.9.4, primary and fallback gateway smokes returned expected responses, and guard invariants passed.

## Limitations
Do not treat older July notes as evidence for this engine-floor issue. Re-check the current package engines on every future update.
