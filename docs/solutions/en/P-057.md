# P-057. The saved proxy upstream was stale and stopped resolving

[Русская версия](../P-057.md)

**Evidence status:** Partially verified by a 2026-09-23 maintenance receipt. A working node was selected on the repair date; subscription lifetime and long-term validity were not proven.

## Time and conditions
2026-09-23, the same iMac Gemini proxy repair.

## Symptoms
The saved Reality upstream returned NXDOMAIN; local SOCKS was also down, so there were at least two failure causes.

## Observations vs actions
The operator restored the listener, then separately checked old DNS, refreshed the subscription with the operator’s explicit consent, and tested current candidates without publishing secrets.

## Causal hypothesis
The old provider node had disappeared from DNS/subscription output; after refresh a working node was available, and a Poland Reality outbound was selected.

## What would not have helped
Only starting sing-box was not enough; the process could listen while forwarding to a nonexistent upstream. Publishing subscription URL/UUID/keys/raw config was forbidden.

## What helped
Refreshing the subscription read-only/with consent, testing candidates with smokes, and moving sing-box DNS to the macOS system resolver helped.

## Result check
Gemini `/app` returned HTTP 200 without an unsupported-country marker, and the listener was up.

## Limits
VPS xray still used the old upstream and returned connection resets in that receipt; this case does not prove VPS proxy repair.

## Basis
Basis: scoped Brain maintenance/lesson/canon records and git history in this documentation branch. Raw logs, private paths, domains/IPs, emails, secrets, and configurations are intentionally not published.
