# P-023. Local proxy was blocked by private-address protection

**Status:** the code defect and inter-agent smoke are confirmed; a separate post-patch Gemini API smoke was not found in the receipt.

[Русская версия](../P-023.md)

## Symptom
OpenClaw was configured to use an explicit proxy on a local/private address, but the request dispatcher blocked that address as private/internal/special-use. Handoff or provider requests that needed the local proxy could fail with a blocked hostname/IP message even though an upper policy layer allowed it.

## Conditions
The incident was handled as a narrow 2026-05-31 repair. The approved scope was only the OpenClaw runtime path: do not touch xray, do not change the Google/Gemini proxy listener, do not change the iMac route, and do not repair MCP auth at the same time.

## Cause
The `allowPrivateProxy` flag was lost between configuration layers. The provider request proxy was already configured as explicit proxy and carried private-proxy permission; the policy builder knew how to check that flag. The function constructing the dispatcher override did not pass it through, so the final dispatcher policy still treated the private proxy as forbidden.

## Actions taken
After a backup, the active runtime bundle was patched to pass `allowPrivateProxy` into the explicit-proxy object. Only the OpenClaw gateway was restarted. xray, proxy ports, iMac routing, and MCP configurations were not changed, which keeps the evidence scoped.

## Verification
After restart, the gateway was active. Two inter-agent smokes passed in both directions: Hermes→Talos and Talos→Hermes returned the expected short markers after the dispatcher patch. Core user services, including Hermes/OpenClaw gateways, watchers, and MCP services, were checked active.

## Limitations
The available receipt does not include a separate post-patch Gemini model/API smoke through this repaired dispatcher. Public status should therefore be precise: private proxy propagation was fixed and handoff smoke passed; a full Gemini provider-path proof is not closed by this document alone.

## Related cases
This is the lower transport layer behind [P-022](P-022.md): if regional access requires a local proxy, the runtime must explicitly allow that private proxy. It also shows why private/internal IP guards need scoped overrides, not global disablement.
