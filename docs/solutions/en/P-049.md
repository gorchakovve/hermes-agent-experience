# P-049. Watcher picked up service files together with tasks

**Русская версия:** [../P-049.md](../P-049.md)

## Status
**Not verified as an implemented repair.** The internal lesson records the pattern and verification checklist, but the found records do not contain a targeted diff for the live watcher plus a post-change smoke for this exact problem.

## Conditions
- Observation date: 2026-06-14.
- Surface: Hermes↔Talos Brain inbox watchers.
- Actors: multiple inotify watchers observe one inbox; one handles tasks, another handles results, and another may log/react to every file.

## Symptoms
One watcher reacted to every created file in the inbox, including dot/temp/service artifacts and non-task/non-result files. With multiple watchers on one directory, this creates risk of races, duplicates, and incorrect semantic role handling.

## Cause / hypothesis
Handling was split across multiple watchers instead of one router per inbox. Dot/temp/result/frontmatter filtering could occur too late or in the wrong watcher, letting a service file cause side effects.

## Failed sequence
1. A tool or editor creates a temporary/dot file in the inbox.
2. An inotify watcher sees any created file.
3. The watcher logs or starts processing without early semantic filtering.
4. Duplicate runs, false task runs, or noisy results may occur.

## Recommended successful sequence
1. Prefer one watcher process per inbox directory.
2. Immediately discard dot/temp files inside it.
3. Route `*-result` files separately to the result handler.
4. Check frontmatter/type task before invoking the task handler.
5. Before disabling an “extra” watcher, confirm its useful behavior is migrated or intentionally retired.
6. Smoke: a real task produces exactly one result; a synthetic result does not start a task; a dot/temp file has no side effect.

## Verification
The source contains a verification pattern: count watchers, verify enabled service, smoke a real task, smoke a synthetic result, and smoke a dot/temp file. No record was found showing this smoke after a concrete change.
