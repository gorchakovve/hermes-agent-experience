# P-051. Hermes Desktop lost a healthy VPS because the local tunnel was stale

[Русская версия](../P-051.md)

**Evidence status:** Verified by an internal maintenance receipt dated 2026-09-23. The repair was scoped; this did not prove long-term SSH-session stability.

## Time and conditions
2026-09-23. Intel Hermes Desktop was used as a remote UI for production Hermes on the VPS through a local loopback SSH forward. Telegram, the VPS Dashboard/Gateway, and the production backend were checked separately.

## Symptoms
Desktop could not connect to the backend. A local listener existed, so the failure looked like a Desktop or auth problem, but the old SSH session returned refused forwarded-channel connections.

## Observations vs actions
Hermes/the operator first checked the VPS backend: version, Dashboard/Gateway, API status, and Telegram were healthy. The local forwarded API and Desktop logs were then checked separately. The only change was restarting the local tunnel launch job and relaunching Desktop. the operator did not rotate credentials; Talos/OpenClaw and proxy routing were not involved.

## Causal hypothesis
The best-supported cause is a stale SSH forward between Desktop and the VPS. Backend and OAuth were ruled out by live checks: the VPS API worked, and after restarting the same tunnel Desktop immediately saw the remote backend.

## What would not have helped
Updating Desktop, changing OAuth, touching the reverse SSH route, changing xray/Gemini proxy, or restarting VPS services would have been off-scope.

## What helped
Check the VPS API directly; check the local forwarded API; inspect a fresh Desktop attempt; restart only the tunnel job; then relaunch Desktop.

## Result check
After repair, the tunnel API returned a healthy VPS Hermes, Desktop logged remote-backend readiness, and authenticated WebSocket checks for events and PTY opened through the local tunnel.

## Limits
Desktop remained compatible but not newest. A later 401, model error, or UI regression is a different incident class, not proof that the tunnel failed again.
