# P-067. A container name did not prove the AmneziaWG version

[Русский](../P-067.md) · [Index](../../problem-index.en.md)

**Status:** confirmed read-only finding. No update was needed, and deleting the “old” image would have been risky.

## When and conditions
2026-09-26, AmneziaWG/VPN inventory before a possible update and cleanup.

## Symptoms
A container name, image tag, or version string could have led to the false conclusion that the working VPN was outdated and needed an update or restart.

## Cause
The container tag, client app, tools, kernel module, upstream tag, and internal version string are separate layers. In addition, the image with “go” in its name was an ancestor of the active container, not proven safe garbage.

## What helped
The check separated active process/interface, tools, kernel module, installed package, and upstream commit/tag. Cosmetic cleanup was stopped until an image or rollback artifact was proven unused.

## Verification
The installed package matched the current upstream commit for the running kernel; the interface was up; read-only Google AI network probes responded. The module was not updated and a healthy VPN was not restarted.

## What is not proven
Read-only probes do not prove every physical client works and do not replace device-level tests on phones or work machines.
