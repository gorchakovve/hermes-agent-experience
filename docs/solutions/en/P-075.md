# P-075. Canon and live agent versions diverged

**Status:** confirmed as a recurring problem class. One OpenClaw version-alignment repair on 2026-07-15 is proven; full synchronization of every document and runtime was not proven.

**Русская версия:** [P-075](../P-075.md)

## Timeframe and conditions
This class appeared across multiple updates; the strongest confirmed example is 2026-07-15. The system had a VPS gateway, CLI shims, plugins, desktop clients and canonical documents that update through different paths.

## Symptoms
A document or index could say “current” while live runtime showed otherwise: gateway on one version, plugins behind, a system CLI/symlink pointing at a legacy install, or a desktop client delayed by a modal/update flow.

## Confirmed cause vs hypothesis
Confirmed: canon was a map and rule set, not an automatic live inventory. On 2026-07-15 the active gateway was already on the stable version, but two official plugins were still on the previous version. A separate system CLI path was older and deliberately left as known drift because active service/remote paths used the correct CLI.

Not confirmed: that every stale document was repaired or every desktop client was aligned on the same day.

## Actor attribution and actions
The operator compared active gateway version, matching CLI, plugin versions, desktop state and protected areas. A rollback anchor was created before plugin changes. Only the lagging plugins were updated, only the gateway was restarted, and then postflight was run.

What was not touched: the main VPN/proxy route, reverse routes, device permissions and unrelated services. What was not “fixed for neatness”: the old root-owned symlink, because it was not the active runtime path.

## Practical verification
Check more than one `--version`:

```sh
<agent-cli> --version
systemctl --user is-active <gateway-service>
curl -fsS http://127.0.0.1:<gateway-port>/health
<agent-cli> plugins list
```

For a desktop client, separately check About/version, updater modal state and actual backend connectivity.

## Proof of result
After the 2026-07-15 repair, the gateway service, Hermes, MCP and handoff watchers were active; local health endpoints responded; matching CLI and gateway reported the same version; the two plugins were aligned. The iMac desktop update remained a follow-up because an approval modal was active.

## Limits and open items
This case does not prove global synchronization of all documentation. It proves the method: live runtime wins over stale notes; known drift must be named, not hidden.

## Lesson
Version truth is not one document and not one CLI. Agent systems need source-of-truth docs plus live inventory and explicit exceptions: updated, deferred, and safely accepted drift.
