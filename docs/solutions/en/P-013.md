# P-013. The watchdog emitted critical alerts because its baseline was stale

**Русский:** [P-013](../P-013.md)

**Status:** confirmed result for the false positives found on 2026-06-15. This does not prove the monitor will catch every future failure.

## Timing and conditions
The incident happened after the inter-agent watcher layout changed and new legitimate systemd files appeared for a Brain watchdog. The old monitor was still comparing the host against the previous baseline.

## Symptoms
The user received alerts that looked critical: watcher services were allegedly missing, and new control files looked suspicious. On inspection, the working handoff route had already changed and the new files belonged to approved automation.

## Cause
Confirmed cause: baseline drift. The monitor still required retired units and did not know about legitimate Brain watchdog files. Short-lived high UDP listeners added noise because they could appear in a single scan.

## Agent/user distinction
The user needed to know whether the alert meant compromise/outage or noise. The agent had to separate retired units from current required units without disabling authorization checks or “fixing” the host by starting old services.

## What did not help or was risky
- Starting retired watcher services just to make the watchdog green: that would restore old architecture.
- Disabling the watchdog entirely: noise would disappear together with useful alerts.
- Whitelisting every new file without provenance: that would weaken access monitoring.

## What worked
1. Compared the old and current watcher/handoff route.
2. Removed retired units from the required-service list.
3. Added legitimate Brain watchdog files to the baseline.
4. Required transient UDP listeners to persist across scans before alerting.
5. Kept gateway, current watcher, and access-signal checks enabled.

Safe checks:

```bash
systemctl --user list-units '*watch*' --no-pager
python -m py_compile path/to/watchdog.py
python path/to/watchdog.py --status
```

## Verification
Watchdog scripts compiled. Direct runs cleared stale service alerts; infrastructure issue state and active access alerts were empty. Current gateway and watcher units were active.

## Limits
This fixed known false positives. The receipt does not include a separate injected-failure test proving false negatives are impossible.

## Evidence and confidence
Evidence: 2026-06-15 “Watchdog Noise Baseline Alignment” maintenance receipt and Hermes review. Confidence: high for the noise fix; medium for future monitoring completeness.
