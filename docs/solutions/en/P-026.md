# P-026. Notion MCP broke strict tool-schema validation

**Status:** confirmed workaround: read-only Notion MCP remained usable; write/mutation tools were not restored by this repair.

[Русская версия](../P-026.md)

## Symptom
When Notion MCP was connected with mutation tools enabled, the agent client failed or refused normal responses because strict tool-schema validation rejected some tools. The failure looked like schema/invalid_function_parameters, not like Notion API unavailability.

## Conditions
The incident involved a Hermes/OpenClaw runtime using strict function/tool schema validation. Notion MCP v2.x exposed tools whose write-tool schemas were incompatible with that client. Preserving Notion search/read was more important than risking the entire reply path for writes.

## Cause
Specific Notion mutation tools, including data-source creation and page patching, had JSON schemas that did not pass client validation. This did not prove a bad token: read-only Notion self/page/list scenarios passed in other checks.

## Actions taken
Operators restricted Notion MCP to a verified read-only set: search, page/block reads, and data-source reads. This was an intentional safe mode, not a full Notion shutdown. Write tools should return only after schema checks on current versions and separate mutation smokes.

## Verification
After the restriction, the gateway stayed active, the main smoke passed, and a stress run completed without fresh schema/HTTP 400/invalid_function_parameters messages. Later registries describe Notion MCP as a standalone/Hermes-facing capability, but Talos/OpenClaw Notion entries must not be re-enabled automatically without valid-token smoke.

## Limitations
This repair does not restore Notion page creation or mutation through MCP. It proves only that read-only mode removed the schema breaker from the active toolset and let the agent respond reliably.

## Operational lesson
Do not confuse schema 400 with auth 403. If a strict client breaks on MCP tool schema, narrow the allowlist to read-only first, preserve useful reading, and test mutation tools separately. Adjacent unconfirmed 403/env cases are [P-027](P-027.md) and [P-028](P-028.md).
