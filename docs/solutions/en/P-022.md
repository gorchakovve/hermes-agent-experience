# P-022. Direct VPS access to Gemini was region-restricted

**Status:** confirmed on the check date; a split-proxy workaround was accepted, but upstream regional availability can change.

[Русская версия](../P-022.md)

## Symptom
A direct VPS request to the Google Generative Language API returned a location-based refusal. That meant Gemini fallback could not be treated as ordinary direct HTTPS from the VPS.

## Conditions
Hermes and Talos/OpenClaw ran on the same VPS. Hermes used a local SOCKS entrypoint for the Gemini proxy, while OpenClaw expected an explicit HTTP(S) proxy. Supplying a SOCKS URL to OpenClaw produced a separate transport/configuration error and did not solve the regional block.

## Cause
The cause was not just the model or API key. The VPS datacenter egress was region-blocked by Google AI. A second engineering cause was client incompatibility: one runtime accepted SOCKS5, the other required HTTP proxy semantics. One local port could not safely serve both clients without adaptation.

## Actions taken
Operators created a separate HTTP entrypoint for OpenClaw on the same protected xray route while preserving Hermes' SOCKS entrypoint. The OpenClaw Google provider was then pointed at the HTTP proxy and only the required gateway was restarted. That split became an invariant: Hermes keeps the SOCKS route; Talos/OpenClaw keeps the HTTP route.

## Verification
After the change, the Google API through the HTTP proxy returned HTTP 200 and a model list; the invalid `socks5` URL error disappeared. A Talos Telegram smoke on Gemini also passed. Later Brain registries keep both proxy listeners as protected invariants that must not be removed during updates.

## What is not proven
The check proves that route on that date, not permanent upstream suitability. It also does not prove that every Google UI service, NotebookLM, or signed-in browser flow works through the same route; those require separate signed-in acceptance, as in [P-025](P-025.md).

## Operational lesson
When direct datacenter access returns regional refusal, do not rotate keys blindly. Separate direct egress, proxy egress, and the proxy format supported by the client. For OpenClaw/Hermes, separate HTTP and SOCKS entrypoints were compatibility, not redundancy.
