# P-033. A secondary Hermes profile did not have its own Canva OAuth state

[Русский](../P-033.md) · [Index](../../problem-index.en.md)

**Status:** open for the secondary profile; the default profile worked, but that does not authorize a separate profile.

## Conditions and symptoms

On 26 September 2026, two Hermes profiles were checked: the default profile and a separate research profile. The default profile connected to Canva MCP and discovered tools. The second profile listed Canva but did not have its own OAuth token cache. Its test failed with a non-interactive/no cached tokens message, and the gateway repeated warnings periodically.

## Cause and testable hypothesis

OAuth state is profile-scoped. A token in the default profile does not authorize the secondary profile. That isolation is intentional: a separate agent should not silently inherit another profile's credentials.

For a similar case, use:

```sh
hermes --profile SECONDARY_PROFILE mcp login canva
hermes --profile SECONDARY_PROFILE mcp test canva
```

Replace `SECONDARY_PROFILE` with your profile name. The login must happen interactively through the user's browser/approval flow. OAuth codes, callback URLs and tokens must not be pasted into chat or copied from another profile.

## What helped / what remains

The useful step was profile-specific diagnosis: the default and secondary profiles were separated, and a gateway warning was not treated as a restart issue. The secondary profile still needs its own interactive authorization. The alternative is to remove Canva only from that profile if the owner explicitly decides it does not need it.

## Validation and limits

The record says the default profile discovered Canva tools, while the secondary profile still failed with no cached tokens. Therefore the fix is not verified; this article records the cause and safe next action only.

## Evidence

Evidence: private records of a Canva MCP check dated 26 September 2026 and the secondary-profile decision dated 25 September 2026. Tokens, callback data and raw logs are omitted.
