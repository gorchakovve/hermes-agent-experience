# P-052. Desktop 401 was an expired Codex OAuth credential on the VPS

[Русская версия](../P-052.md)

**Evidence status:** Verified by a 2026-09-24 maintenance receipt. The fix was checked with live smokes; the next refresh remained a future risk.

## Time and conditions
2026-09-24. Hermes Desktop on the Intel iMac used the VPS-backed openai-codex route. The previous day had already shown that the tunnel and remote UI could work.

## Symptoms
Desktop showed `HTTP 401: Provided authentication token is expired`. It looked like a Desktop login problem, but the failure came from the VPS-backed model route.

## Observations vs actions
The operator checked Desktop remote mode, tunnel health, and backend health separately, then inspected server-side auth evidence. the operator only participated in the interactive device-code OAuth step where required. Talos/OpenClaw was not moved to this OAuth route and its auth files were not changed.

## Causal hypothesis
The confirmed cause was that the old Hermes Codex refresh token had already been consumed by another client/path and had become terminally invalid. This was not a tunnel failure and not a broken Desktop binary.

## What would not have helped
Restarting the tunnel, reinstalling Desktop, or sharing one refresh token across agents would have been unsafe: it hides the single-owner problem and can invalidate the credential again.

## What helped
A new OAuth credential was created for Hermes through an interactive device-code flow; active tasks were checked; only dependent Hermes services were restarted; only the proven-invalid old credential was removed.

## Result check
Two primary-model sentinel smokes returned the expected strings. No fresh 401/token-expired/reused-token errors appeared after the smoke; gateway, Telegram, the Desktop tunnel endpoint, and Desktop readiness were checked.

## Limits
Tokens and raw auth state are not public. The check proves the repair at that date; it does not guarantee indefinite OAuth validity or prevent a future reused-token event.

## Basis
Basis: scoped Brain maintenance/lesson/canon records and git history in this documentation branch. Raw logs, private paths, domains/IPs, emails, secrets, and configurations are intentionally not published.
