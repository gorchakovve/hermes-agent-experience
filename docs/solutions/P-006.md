# P-006. Desktop и VPS OpenClaw разошлись по версиям

**Статус:** подтверждён записью восстановления Desktop 2026-07-15.

**Основание:** MAINTENANCE-записи от 2026-07-15: version alignment и stale Desktop pairing recovery; прямые наблюдения pending requests на VPS, состояния approval/connection для node, gateway logs и версии app. Сырые журналы, приватные пути, токены, домены и адреса не публикуются.

**EN:** [`P-006.md`](en/P-006.md)

## Симптомы
Desktop снова и снова показывал модальное окно Approve Mac repair. Нажатие approve не решало проблему, хотя gateway был здоров.

## Условия и время
iMac Desktop 2026.6.11 и VPS gateway 2026.7.1, 2026-07-15.

## Гипотеза / причина
На VPS не было pending requests, а iMac node уже был approved/connected. Gateway logs показывали approve для устаревшего request ID. Это указывало на stale client-side approval loop, а не на недостаток прав на VPS.

## Что сработало
Approved device не удаляли и permissions не расширяли. Сделали локальную recovery copy, разрешили приложению установить уже скачанный verified updater payload и перезапустили только Desktop client.

## Проверка результата
Desktop и подключённый node стали 2026.7.1; node остался approved/connected; pending requests отсутствовали; новых unknown requestId pairing errors не наблюдалось.

## Ограничения
Наличие скачанного payload не означает, что app уже обновился. Version skew не доказывает любую проблему pairing, но в этом случае stale request loop подтверждён evidence gateway.
