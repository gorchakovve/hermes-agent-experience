# P-030. Первое ограничение Workspace MCP адресом localhost остановило сервис

**Статус:** подтверждённый итоговый hardening; первая попытка не разобрана до точной строки ошибки.

[English version](en/P-030.md)

## Симптом
Первая попытка ограничить Workspace MCP bind-адресом localhost привела к отказу запуска сервиса. Это был hardening-заход: цель — убрать внешний bind без потери локального MCP endpoint для Hermes/Talos.

## Условия
До hardening сервис уже был рабочим и обслуживал Workspace MCP на VPS. Требовалось сохранить streamable HTTP/MCP compatibility и доступ двух аккаунтов, но сделать listener loopback-only. В отличие от [P-029](P-029.md), речь здесь не о выборе entrypoint/аргументов, а о сетевом bind.

## Причина или установленный обход
Postmortem подтверждает факт неудачной первой попытки и отката, но не содержит достаточно публичных данных, чтобы назвать точную строку ошибки. Успешная реализация использовала поддерживаемую настройку bind на loopback, не ломая уже рабочий entrypoint.

## Что было сделано
Первый вариант откатили. Затем в закрытый env сервиса добавили host override, перезапустили Workspace MCP и проверили, что он слушает только loopback. Публичные/внешние обращения к порту стали недоступны, а локальные health и MCP initialize остались рабочими.

## Проверка результата
Сервис был active, listener находился только на loopback (`127.0.0.1:<service-port>`), локальный health отвечал healthy, MCP initialize/list-tools проходил, а прямой доступ к порту извне был заблокирован или недоступен. Read-only Workspace проверки для двух аккаунтов проходили на дату hardening.

## Ограничения
Это подтверждённый обход и итоговый smoke, а не полная root-cause экспертиза первой неудачной попытки. Если будущий клиент должен подключаться с другого host, нельзя просто вернуть public bind: нужно отдельное решение по туннелю, firewall и auth.

## Практический вывод
Для service hardening меняйте одну ось за раз: сначала сохраните рабочий entrypoint, затем задайте поддерживаемый loopback bind, затем проверьте listener, локальный MCP smoke и внешний denial. Не редактируйте package/cache код ради bind, если сервис уже поддерживает настройку адреса.
