# P-023. Локальный proxy блокировался защитой приватных адресов

**Статус:** кодовый дефект и межагентный smoke подтверждены; отдельный Gemini API smoke после патча в найденном receipt отсутствует.

[English version](en/P-023.md)

## Симптом
OpenClaw был настроен использовать явный proxy на локальном/private адресе, но диспетчер запросов блокировал такой адрес как private/internal/special-use. В результате handoff или provider-запросы, которым нужен локальный прокси, могли завершаться сообщением о заблокированном hostname/IP даже при корректной политике выше по цепочке.

## Условия
Инцидент произошёл в узкой задаче 2026-05-31. Пользователь разрешил только точечный ремонт OpenClaw runtime: не трогать xray, не менять Google/Gemini proxy listener, не менять iMac route и не чинить MCP-auth заодно.

## Причина
Разбор показал потерю флага `allowPrivateProxy` между слоями конфигурации. Provider request proxy уже был сконфигурирован как явный proxy и нёс разрешение private proxy; policy-builder умел читать этот флаг. Но функция, собиравшая override для dispatcher, не передавала флаг дальше, поэтому конечная policy считала private proxy запрещённым.

## Что было сделано
После резервной копии в активный runtime bundle добавили передачу `allowPrivateProxy` в объект явный proxy. Затем перезапустили только OpenClaw gateway. xray, сами proxy-порты, iMac и MCP-конфигурации не менялись. Это важно для аудита: успешный результат нельзя объяснить побочным перезапуском или заменой upstream.

## Проверка результата
После перезапуска gateway был active. Два межагентных smoke прошли в обе стороны: Hermes→Talos и Talos→Hermes вернули ожидаемые короткие маркеры после патча dispatcher. Также были проверены ключевые пользовательские сервисы, включая Hermes/OpenClaw gateway, watchers и MCP-сервисы.

## Ограничения
Доступный receipt не содержит отдельного Gemini model/API smoke после патча именно через исправленный dispatcher. Поэтому публичный статус точнее формулировать так: передача private proxy исправлена и handoff smoke прошёл; полное доказательство маршрут Gemini provider этот документ не закрывает.

## Связанные случаи
Этот случай является нижним транспортным слоем для [P-022](P-022.md): если региональный доступ требует локального proxy, runtime обязан уметь явно разрешать private proxy. Он также объясняет, почему защитные проверки private/internal IP должны иметь scoped override, а не отключаться глобально.
