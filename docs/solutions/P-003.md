# P-003. Обновление OpenClaw попало в неактивный пакет

**Статус:** подтверждён записью обновления 2026-07-02.

**Основание:** запись MAINTENANCE от 2026-07-02; прямое сравнение цели updater, активного дерева пакетов, версии CLI, service health и public guard. Сырые журналы, приватные пути, токены, домены и адреса не публикуются.

**EN:** [`P-003.md`](en/P-003.md)

## Симптомы
Updater сообщил об установке новой версии, но активные CLI и gateway оставались на прежней версии.

## Условия и время
VPS, 2026-07-02; две локальные установки OpenClaw в разных деревьях npm-пакетов.

## Гипотеза / причина
Updater записывал изменения в неактивное дерево пакетов, а systemd запускал другое, активное дерево.

## Что сработало
Сравнили unit-файл gateway, путь из `command -v openclaw`, версию CLI и фактическое дерево Node-модуля. Исправили helper-скрипты updater/repair так, чтобы они обращались к активному дереву пакетов; затем повторно применили repair к активной копии и перезапустили gateway.

## Проверка результата
Активный CLI стал 2026.6.11, gateway был active, локальный /health вернул live, public endpoint guard прошёл без failures/warnings.

## Ограничения
Не копируйте runtime-пути между хостами: сначала обнаружьте активный путь service/package. Первая успешная запись об install в логах не доказывает, что обновился runtime.
