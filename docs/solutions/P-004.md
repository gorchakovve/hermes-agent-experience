# P-004. Плановому обновителю не хватало версии Node.js

**Статус:** подтверждён записью обновления 2026-09-16.

**Основание:** MAINTENANCE-запись от 2026-09-16; прямое сравнение system Node, минимального engine floor пакета, выделенного runtime, исполняемого файла сервиса и результата updater. Сырые журналы, приватные пути, токены, домены и адреса не публикуются.

**EN:** [`P-004.md`](en/P-004.md)

## Симптомы
Плановые обновления OpenClaw перестали завершаться после повышения минимальной версии Node.js в пакете.

## Условия и время
VPS, 2026-09-16; обновление OpenClaw 2026.9.2 → 2026.9.4.

## Гипотеза / причина
Системный Node был ниже нового engine floor пакета. Updater и service/CLI требовали закреплённого runtime, но менять системный Node было рискованно.

## Что сработало
Установили отдельный официальный runtime Node, предварительно проверив архив по официальному SHA-256-манифесту; закрепили этот runtime для service/CLI и исправили PATH еженедельного updater. Системный Node и Hermes runtime не меняли.

## Проверка результата
Updater завершился, gateway использовал выделенный runtime Node, CLI сообщил 2026.9.4, primary и fallback smoke-проверки gateway вернули ожидаемые ответы; guard-инварианты прошли.

## Ограничения
Не считайте старые июльские записи доказательством engine-floor проблемы. При следующем обновлении нужно заново проверить текущий поле engines пакета.
