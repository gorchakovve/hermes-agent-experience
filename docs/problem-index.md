# Индекс проблем: Hermes, OpenClaw, VPS и устройства

88 пронумерованных разборов: 88 отдельных инцидентов и эксплуатационных находок за апрель—сентябрь 2026 года. Статус обозначает **подтверждение пригодного решения по доступным записям**, а не гарантию вечной работоспособности: 40 подтверждено, 34 частично подтверждено, 14 открыто. Для подтверждённого обхода первопричина тоже может оставаться неизвестной — см. ограничения в статье. Первичные закрытые записи проверены, но не опубликованы.
